# رساس: الواجهة الجديدة

تصميم جديد من الصفر على نمط المراجع، ومبني على منتجات رساس الحقيقية من زد.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `product.html`: صفحة المنتج على تخطيط المرجع 3 (NOIR). تعمل لأي منتج عبر `product.html?id=<أول 8 أحرف من معرّف المنتج>`، والافتراضي العود الملكي.
- `category.html`: صفحة التصنيف، مثل `category.html?c=special`. الأقسام: all, special, inspired, classic, oils, oud, home, hair, kids, gifts. فيها تصفية بالحجم والسعر والخصم، وترتيب، و«عرض المزيد».
- `cart.html`: السلة: تعديل الكمية والحذف، وملخص الطلب شامل الضريبة، وسطر التقسيط، وحقل كود الخصم، ومقترحات «أضف لطلبك». أضف `?demo=1` للرابط لتمتلئ السلة بثلاثة منتجات للمعاينة.
- `assets/css/style.css`: كل التصميم. الألوان والخطوط في أعلى الملف كمتغيرات.
- `assets/js/main.js`: الهيرو المتحرك، والتبويبات، والقائمة الجانبية، والسلة التجريبية، وصفحة المنتج، وصفحة التصنيف وتعريف أقسامها (`CATEGORY_PAGES`).
- `assets/js/data.js`: 191 منتجاً منشوراً ومتوفراً من زد بتاريخ 2026-10-28. الأسعار شاملة الضريبة 15%.
- `assets/img/logo.png`: شعار رساس.

## المعاينة
```
python -m http.server 8088 --directory new-store
```
ثم افتح http://localhost:8088

## ما زال ناقصاً
- مدة التوصيل `[X–Y]` في صفحة المنتج.
- أوصاف المنتجات: العود الملكي فقط منقول وصفه من المتجر. باقي المنتجات تعرض تنبيهاً حتى تُربط بزد.
- السلة والمفضلة والنشرة تجريبية داخل المتصفح فقط، ولا ترسل شيئاً لزد. زر «إتمام الطلب» وكود الخصم يعملان فعلياً فقط بعد الربط بصفحة الدفع في زد.
- الصور الناقصة في صفحة المنتج: العلبة، والعطر مع مكوناته، وعلى اليد.

# تصميم متجر رساس

تصميم الصفحة الرئيسية لمتجر رساس (resas.sa.com) على ثيم Soft في زد.

- `storefront/proposals/luxury-home.html`: الاقتراح التفاعلي للصفحة الرئيسية (النسخة المعتمدة).
- `zid-theme/soft-v2/resas-soft.css` و`resas-soft.js`: الملفان اللذان يُلصقان في لوحة زد (CSS مخصص وJavaScript مخصص). الشرح في `zid-theme/soft-v2/README.md`.
- `DESIGN.md`: عقد التصميم (الألوان، الخطوط، المسافات، الأيقونات).
- `معاينة-كل-النسخ.html`: فهرس كل النسخ.

المنتجات والأسعار في `storefront/data/store.js` نسخة محفوظة من بيانات المتجر (الأسعار + ضريبة 15%)، وقد تختلف عن المتجر الحي. صور المنتجات تُحمَّل من خوادم زد.
